# 🏥 MaSanté - Plateforme e-Santé

Application web full-stack permettant la gestion des traitements et des rendez-vous médicaux.

## 🚀 Fonctionnalités principales :
- **Espace Patient :** Rappels intelligents avec alarme, validation de prise par scan de code-barres (caméra), suivi du stock, prise de rendez-vous.
- **Espace Médecin (Pro) :** Tableau de bord d'observance, création de prescriptions, validation des rendez-vous, inscription des patients.

## ⚙️ Stack Technique :
- **Frontend :** React.js
- **Backend :** Laravel
- **Base de données :** MySQL
